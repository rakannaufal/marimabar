# Pemetaan implementasi desain

Acuan: `prd.md` dan `Rules.md` untuk perilaku/privasi; `desain.md` untuk gaya; `design/*/code.html` ialah desain asli yang wajib dicakup dan dicocokkan per layar, bukan referensi bebas. Peta 32 layar ada di `design-coverage.json`. HTML memakai Tailwind CDN, konfigurasi berbeda per halaman, `href="#"`, data contoh, dan handler JavaScript/`alert`; jangan salin sebagai aplikasi atau kontrak data.

## Sistem visual yang disatukan

- Token kanonik dari `desain.md`/`Rules.md`: kanvas `#14141C`, kartu `#1E1E29`, teks `#F5F3EE`, lime `#C8FF4D`, violet `#8B7CFF`; elevasi `#272736`/border `#2E2E3E`, teks sekunder sekitar `#9E9EAF`. Teal `#4ADE80` dan coral `#FF6B5E` **hanya** status semantik. HTML kadang memakai `#13131b`, lime `#bef443`, violet `#c7bfff`, bahkan `primary: #fff`; normalkan, jangan impor token Tailwind per-file apa adanya.
- Plus Jakarta Sans 700–800 untuk heading/angka (display ~48/56 desktop, ~32–36/40–44 mobile), Inter 400–600 untuk isi (~15–16/24). Sumber `design/mabar_finder_ui/DESIGN.md` lebih sesuai dengan HTML halaman dibanding `design/elevated_social_matchmaking_hub/DESIGN.md` yang memakai Outfit/DM Sans; jangan campur keluarga font.
- Kontainer publik maksimal 1240–1280px dengan padding 16px ponsel, 32–48px desktop; sela 8/16/24/32px. Kartu radius 16–24px (beberapa HTML 32px), padding 16px mobile/24px desktop; avatar bulat/ring violet; CTA lime penuh dengan teks gelap dan radius pill. Input gelap elevasi radius ~12px, fokus jelas; badge pill dengan teks status, bukan warna saja.
- Hilangkan `bg-gradient-*`, blob `blur-*` dekoratif, headline dua warna, eyebrow ALL CAPS, angka contoh yang menyaru fakta, klaim online/realtime, emoji/star reputasi. Gunakan overlay foto **flat** `rgba(20,20,28,.75)`, bukan gradasi. Batas dua aksen dekoratif per layar; hormati reduced motion dan fokus keyboard. Material Symbols Outlined pada HTML adalah font eksternal, dapat diganti ikon SVG konsisten tanpa emoji.

## Aset

`design/*/screen.png` ialah screenshot referensi **bukan** aset UI. HTML merujuk gambar jarak jauh `lh3.googleusercontent.com/aida...`/`aida-public...`, font Google, Material Symbols, dan Tailwind CDN; tak ada file gambar siap pakai berlisensi jelas di direktori desain. Jangan hotlink ataupun menyalin gambar AI/gameplay/avatar tersebut ke `public/` tanpa verifikasi lisensi, izin penggunaan, dan atribusi; screenshot game/logo merek juga perlu hak penggunaan. Gunakan SVG ikon generik buatan sendiri, placeholder avatar inisial/warna solid, kartu game tipografi, serta gambar gameplay berizin setelah diperoleh; beri `alt`, dimensi, lazy-load untuk nonhero. Tidak ada aset yang disalin ke `public/design-assets/`.

## Prioritas konflik

`Rules.md` menetapkan urutan `prd.md` → arsitektur/skema → `desain.md`/`design/`. Khusus route, `desain.md` menandai `/pilih-game`, `/cari/:gameSlug`, `/profil/:userId` untuk user, tetapi PRD mengizinkan guest melihat katalog dan profil publik. Pertahankan akses baca guest; lindungi hanya ajakan/chat/edit. `desain.md` sendiri menyebut overlay gradasi pada beberapa prompt halaman dan pembukaan ID saat accepted; larangan global tanpa gradasi serta privasi PRD mengalahkan contoh itu. Seluruh angka, nama pengguna, statistik, testimoni, label `verified`/`online`, dan opsi filter mockup adalah demonstrasi, bukan seed atau fakta produk.
