Ikhtisar & Komitmen Privasi Kami

Mabar Finder didesain dari awal untuk komunitas game santai dan kompetitif Indonesia. Prinsip kami sangat sederhana: kamu datang untuk bermain, bukan untuk dimata-matai. Kami hanya mengumpulkan data yang benar-benar esensial untuk membuat sesi mabar berjalan lancar, adil, bebas cheater, dan minim toxic.

lock_reset

Janji Tanpa Jual Beli Data

Kami tidak pernah dan tidak akan pernah menjual, menyewakan, atau memperdagangkan data pribadimu ke pihak pengiklan luar, broker data komersial, maupun entitas telemarketing pihak ketiga mana pun.

1

Data yang Kami Kumpulkan

Kami membagi data yang kami terima menjadi dua kategori utama agar kamu tahu dengan pasti apa yang kami simpan:

badge A. Informasi Profil & Otentikasi
  • Nama Tampilan & Username: Nama yang kamu pilih untuk identitas sosial di Mabar Finder.
  • Alamat Email: Digunakan secara eksklusif untuk verifikasi keamanan akun, reset kata sandi, dan notifikasi penting.
  • Foto Profil / Avatar: Gambar yang kamu unggah secara sukarela atau avatar default sistem.
  • Kredensial Terenkripsi: Kata sandi di-hash menggunakan algoritma modern standar industri (Argon2/Bcrypt).
router B. Data Teknis & Telemetri Jaringan
  • Estimasi Lokasi Regional: Deteksi server terdekat berdasarkan IP (contoh: Jakarta, Surabaya, Medan) demi mencocokkan ping rendah antarpemain.
  • Spesifikasi Perangkat Dasar: Tipe sistem operasi dan peramban untuk memastikan kestabilan web-client.
  • Log Keamanan Anti-Spam: Waktu aktivitas masuk untuk mencegah aksi pengambilalihan akun secara tidak sah.
2

Tujuan Penggunaan Informasi

Semua data yang masuk diproses dengan tujuan fungsional nyata untuk menyajikan matchmaking instan:

hub Algoritma Matchmaking Akurat

Mempertemukan tier skill yang seimbang sehingga mabar tidak jomplang dan tetap kompetitif secara adil.

forum Kanal Lobi Suara Real-Time

Memfasilitasi pertukaran SDP/ICE kandidat untuk panggilan suara langsung browser-to-browser.

gavel Moderasi Perilaku Toxic

Melindungi kenyamanan komunitas dari AFK berulang, ujaran kebencian, dan pelecehan verbal di lobi.

speed Optimasi Latensi Server

Menentukan routing server socket terbaik di wilayah Indonesia bagian Barat, Tengah, dan Timur.

3

Akun Game & In-Game Tag (IGN)

Saat kamu menghubungkan game seperti Mobile Legends: Bang Bang, Valorant, PUBG Mobile, atau Free Fire ke profil Mabar Finder, berikut batasan ketat yang kami terapkan:

check_circle Yang Kami Tampilkan ke Teman Mabar:

Nama dalam game (IGN), Player ID / Tag publik (contoh: Riot ID #ID1), tier rank saat ini, serta preferensi role hero/agent. Ini diperlukan agar rekan squad dapat mengundangmu di dalam game client resmi.

cancel Yang Tidak Pernah Kami Minta atau Simpan:

Kata sandi game, token otentikasi login Riot/Moonton/Steam, detail pembayaran item mikrotransaksi, atau inventori skin berharga. Kami tidak pernah meminta akses akun internal game kamu.

4

Riwayat Match & Skor Reputasi

Mabar Finder mengusung ekosistem ramah dan suportif melalui fitur Skor Sikap Positif.

Pujian Teman Satu Tim (Endorsements)

Label seperti "Komunikatif", "Shotcaller Handal", atau "Sabar / Chill" ditampilkan secara publik di profilmu untuk menaikkan kesempatan masuk lobi favorit.

Laporan Pelanggaran (Internal Audit)

Laporan toxic, sengaja afk, atau rasisme diproses oleh tim moderator manusia secara tertutup. Identitas pelapor dirahasiakan 100% dari terlapor guna mencegah aksi intimidasi balik.

5

Keamanan & Penyimpanan Data

Infrastruktur server Mabar Finder beroperasi di pusat data tier-3 yang berbasis di Jakarta, Indonesia, sesuai dengan kepatuhan Undang-Undang Perlindungan Data Pribadi (UU PDP No. 27 Tahun 2022).

https
Transmisi TLS 1.3 Setiap paket data antara browser kamu dan kluster kami selalu terenkripsi kuat tanpa celah snooping jaringan Wi-Fi publik.
database
Data At-Rest Encryption Database profil dan log transaksi diamankan menggunakan enkripsi AES-256 tingkat enterprise.
timer
Retensi Lobi Sementara Data ruang lobi mabar yang telah selesai dihapus secara permanen dari memory server dalam jangka 24 jam.
6

Hak & Kontrol Privasi Kamu

Kamu memegang kendali penuh atas identitas mabar kamu. Kapan saja tanpa perlu alasan berbelit, kamu dapat menggunakan hak berikut langsung dari dasbor pengaturan akun:

download Unduh Arsip Data

Dapatkan salinan terstruktur (format JSON) dari semua riwayat mabar, pujian tim, dan in-game tag yang tersimpan.

delete_forever Penghapusan Permanen (Right to be Forgotten)

Hapus profil, riwayat chat lobi, dan relasi tag game seketika tanpa masa tunggu palsu.

7

Perubahan Kebijakan & Kontak

Jika kami melakukan pembaruan substantif terhadap tata cara pengolahan data, kami akan memberitahukan seluruh pengguna melalui banner pengumuman di lobi mabar setidaknya 14 hari sebelum aturan baru berlaku aktif.

Ada Pertanyaan Khusus Terkait Privasi? Surel langsung: privasi@mabarfinder.id
